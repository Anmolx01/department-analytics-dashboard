# Department Analytics Dashboard

## Overview

An interactive Power BI dashboard developed during my Data Analytics internship at DataMelon Labs to analyze department-level business performance.

The dashboard provides insights into sales, transactions, customers, average transaction value, regional contribution, category performance, store formats, and monthly trends.

## Key Features

- Department-level sales and customer analysis
- Regional sales contribution
- Transaction and customer analysis
- Average Transaction Value (ATV)
- Average Selling Price (ASP)
- Units per Trip
- Spend per Customer
- Monthly sales trend analysis
- Category performance analysis
- Store-format performance comparison
- Year-over-year category growth analysis
- Discount and sales relationship analysis

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
- Business Intelligence

## Dashboard Pages

### 1. Department Health
Analyzes department sales, customers, transactions, regional contribution and monthly performance.

### 2. Category Performance
Analyzes category contribution, year-over-year growth, store-format performance and monthly trends.
